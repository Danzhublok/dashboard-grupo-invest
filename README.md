# Imóvel Profit Dashboard

vamos criar um dashboard para uma consultoria de credito para imoveis onde tera o lucro mensal de cada representação, de inicio quero que construa um dashboard com as 5 representações, como no modelo da imagem que enviei, com seu luco mensal, e quizenal, quero que tenha um grafico de pizza tambem para mostrar qual representação teve mais lucro, e um dashboard geral destacando o lucro total com numeros de cotas, de inicio é apenas uma base, porem quero que em cima de cada tabela de representação tenha o nome e a logo em cima, e no hero da pagina tenha a logo principal do grupo, com tematica azul bebe, essa é a logo de exemplo para usar as tonalidades, quero que tenha uma side bar com apenas duas opções de momento, com dashboard. e metas a aba de metas sera um dashboard contabilizando o total de vendas como se fosse um progress bar, com o o ganho total, e a meta, e o quanto falta para bater a meta nesse grafico, quero que seja uma forma bem profissional para apresentar para meus socios representantes
